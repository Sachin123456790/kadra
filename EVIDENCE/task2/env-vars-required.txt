Required environment variables (documented in .env.example):

Deploy/Transfer:
  - SEPOLIA_RPC_URL: Alchemy/Infura Sepolia RPC endpoint
  - DEPLOYER_PRIVATE_KEY: 0x-prefixed 64-hex-char private key (testnet only)
  - TRANSFER_TARGET_ADDRESS: Target Ethereum address for ETH transfer

Coinbase SDK:
  - COINBASE_API_KEY_NAME: Coinbase API key name
  - COINBASE_API_KEY_SECRET: Coinbase API key secret

Legal Entity Simulation (optional env overrides, defaults from data/legal-entity.json):
  - LEGAL_ENTITY_NAME
  - LEGAL_ENTITY_TAX_ID
  - LEGAL_ENTITY_JURISDICTION
  - LEGAL_ENTITY_WALLET_ADDRESS

External Bank Simulation (optional env overrides, defaults from data/bank-accounts.json):
  - BANK_ROUTING_NUMBER
  - BANK_ACCOUNT_NUMBER
  - BANK_ACCOUNT_HOLDER
